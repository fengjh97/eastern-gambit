# 东方棋局 1949–2001 · The Eastern Gambit

单人历史卡牌策略游戏。你扮演新中国，从 1949 年开国走到 2001 年入世，在冷战棋盘上落子。

**在线游玩：https://fengjh97.github.io/eastern-gambit/**

## 玩法

- **五幕 × 7 回合**：建国立足（1949–57）→ 风雨飘摇（1958–65）→ 严峻岁月（1966–76）→ 改革开放（1977–89）→ 走向世界（1990–2001），每幕专属牌堆，共 **210 张史实事件卡**。
- **每回合打 3 张牌**，每张二选一：**打出事件**（许多带抉择与掷骰），或**弃牌换行动点**投入外交/经济/军备/维稳/宣传。
- **危机卡**：弃掉也会触发削弱效果，拖到幕末则全面引爆——冷战热斗式的手牌拉扯。
- **时局骰（Turn Zero）**：每幕开局掷骰决定时代底色，且受上一幕抉择的"历史惯性"修正——全面跃进会让三年困难的骰点大幅恶化。
- **幕末大事**：大跃进抉择、中苏决裂、尼克松访华窗口、1989 结算、入世谈判——大势必然发生，走向由你的准备与选择决定。
- **数值**：稳定/经济/军事/国际地位四项国力（归零即崩局），与苏俄、美、英、欧、日、东南亚、台、朝、韩九条关系轴。
- **11 种结局**：4 种中途崩局 + 7 种终局（世纪跨越 / 韬光养晦 / 负重前行 / 铁血东方 / 最后的红色堡垒 / 两头不靠岸……），另有海峡两岸、东方巨响等隐藏附记。

## 技术

纯静态站（无构建、无依赖）：原生 JS + CSS 动画，WebAudio 合成音效，localStorage 存档。
美术素材由 Nano Banana Pro（Gemini 3 Pro Image）生成：宣传画风海报 + 做旧历史照片。

本地运行：`python3 -m http.server` 后打开 `http://localhost:8000`，或直接双击 `index.html`。

平衡性经蒙特卡洛模拟校准（`tools/sim.js`，900+ 局）：乱玩会滑向孤立与崩局，专注经营才能推开入世之门，完美结局《世纪跨越》需要四线全面经营。
