# 东方棋局 1949–2001 · The Eastern Gambit

单人历史卡牌策略游戏。你扮演新中国，从 1949 年开国走到 2001 年入世，在冷战棋盘上落子。

**在线游玩：https://fengjh97.github.io/eastern-gambit/**

## 玩法

- **五幕 × 7 回合**：建国立足（1949–57）→ 风雨飘摇（1958–65）→ 严峻岁月（1966–76）→ 改革开放（1977–89）→ 走向世界（1990–2001），每幕专属牌堆，共 **210 张史实事件卡**。
- **每回合打 3 张牌**，每张二选一：**打出事件**（许多带抉择与掷骰），或**弃牌换行动点**投入外交/经济/军备/维稳/宣传。
- **危机卡**：弃掉也会触发削弱效果，拖到幕末则全面引爆——冷战热斗式的手牌拉扯。
- **时局骰（Turn Zero）**：每幕开局掷骰决定时代底色，且受上一幕抉择的"历史惯性"修正——全面跃进会让三年困难的骰点大幅恶化。
- **幕末大事**：大跃进抉择、中苏决裂、尼克松访华窗口、1989 结算、入世谈判——大势必然发生，走向由你的准备与选择决定。
- **数值**：稳定/经济/军事/国际地位四项国力（归零即崩局），与苏俄、美、英、欧、日、东南亚、台、朝、韩九条关系轴。

## 博弈系统 —— 对面坐着的是活的对手

每回合结束，一份《内部参考》电报摊在你面前，各国按你这一回合的动作作出**带实效的反应**：

- **阈值爆发**：关系跌破 -6 或升破 +5 触发时代级大事件——【全面遏制】华盛顿禁运（经济-4）、【同盟蜜月】苏援一揽子到位（经济+3 军事+2）、【海峡惊涛】、【南洋排浪】……每幕每国每方向仅一次。
- **阵营连锁**：动美国 ≥3 点，台北、汉城、东京同步跟进；动莫斯科，平壤应声而变。鲁莽外交会被整个阵营反噬。
- **关系区间行为表**：敌对国主动反制（封锁、军演、断援），友好国主动送援。本回合被你动过的国家，反应概率翻倍——**你的每一步都在改变对手下一步的概率分布**。
- **苏美战略议程（暗棋）**：每幕开局，苏美各暗抽一张针对中国的战略议程（共20张）。它每回合向你泄露一条线索，幕末结算：**破解条件达成则对方偷鸡不成蚀把米，未破解则议程得逞**。
- **情报刺探**：花 2 行动点直接截获密电，看到议程全文、破解条件与当前达成状态。
- **历史王牌**：手握三张大国牌——【苏联牌·一边倒】开局即持有、【第三世界牌·万隆精神】随万隆/入联解锁、【美国牌·联美制苏】随尼克松窗口解锁。每幕限打一张，收益巨大，**代价更大**：打出后牌落入对方强权手中两回合（必然报复+议程加速），一边倒还会在中苏决裂时连本带利反噬。邦交面板是一张做旧亚太作战地图，九国徽标随关系值变色发光。

卡面配图为来自维基共享资源的**真实历史照片**（公有领域 / CC 授权，见 [图片来源与授权](credits.html)）。
- **13 种结局**：4 种中途崩局 + 9 种终局——入世线（世纪跨越/韬光养晦/负重前行）、统一线（统一大业）、第三世界线（不结盟旗手）、对抗线（铁血东方）、阵营线（最后的红色堡垒）、漂流线（两头不靠岸），另有隐藏附记与四档史册定评。
- **历史真实的约束**：中美关系有时代天花板（破冰前最高-2，乒乓外交→尼克松访华→建交逐级解锁），无法开局速通美国线；入世谈判要求国内稳定≥40。稳定≥60触发"政通人和"每回合行动点+1——内政就是生产力。每回合可免费换一张手牌。

## 技术

纯静态站（无构建、无依赖）：原生 JS + CSS 动画，WebAudio 合成音效，localStorage 存档。
美术素材由 Nano Banana Pro（Gemini 3 Pro Image）生成：宣传画风海报 + 做旧历史照片。
背景音乐为自由授权的真实录音（东方红一号卫星信号、1963年《东方红》、1977年《国际歌》器乐版等，详见 [授权页](credits.html)），加载失败时回落到 WebAudio 合成版。

本地运行：`python3 -m http.server` 后打开 `http://localhost:8000`，或直接双击 `index.html`。

平衡性经蒙特卡洛模拟校准（`tools/sim.js`，1500+ 局）：熟练玩家约 42% 达成入世线，乱玩则 45% 被各国联手封锁至《铁幕孤岛》崩局。完美结局《世纪跨越》需要四线全面经营 + 破解两强全部议程。
